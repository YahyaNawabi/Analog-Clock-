# 🕰️ Elegant Analog Clock

A beautifully designed analog clock built with **HTML**, **CSS**, and **JavaScript**. This clock shows the current time in both analog and digital formats. The hands of the clock rotate in real-time, and the digital time is displayed below the clock face. The design features smooth animations and a modern glowing effect.

## 🚀 Features

- **Live Analog Clock**: Real-time clock with animated hour, minute, and second hands.
- **Digital Display**: The digital time is displayed below the clock face.
- **Responsive Design**: The clock is designed to look great on all screen sizes.
- **Smooth Animations**: Hands smoothly rotate every second, with dynamic updates.
- **Glowing Effect**: Subtle glowing effects on the clock’s center and hour hands.

## 🛠️ Technologies Used

- **HTML5**: For structuring the clock layout.
- **CSS3**: For styling, animations, and creating the clock face.
- **JavaScript**: For dynamically updating the time and controlling the movement of clock hands.
